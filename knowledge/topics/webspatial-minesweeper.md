# 3D Minesweeper for Apple Vision Pro

I made a volumetric, 3D take on Minesweeper for Apple Vision Pro with the WebSpatial SDK, using React and TypeScript. The minefield is a 3D grid, so every cell has 26 neighbours instead of 8, and it switches between 2D and 3D modes depending on the environment. It has a pixel art look, and uses instancing and level of detail to stay fast.
